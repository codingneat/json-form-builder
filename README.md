# JSON Form Builder

**JSON Form Builder** is an Angular-based application that dynamically generates forms from a JSON prompt. It allows users to input data through the generated form and returns the data in JSON format upon submission.

## 🚀 Features

- 🔧 Generate dynamic forms from JSON configuration
- 📄 Supports various input types (text, number, select, checkbox, etc.)
- 🔁 Outputs user-submitted form data as JSON
- 🧩 Easily extendable for custom form field types and validations

## 🛠️ Technologies Used

- [Angular](https://angular.io/) 17+
- TypeScript
- RxJS
- SCSS / CSS3

## 📦 Installation

`bash
git clone https://github.com/yourusername/json-form-builder.git
cd json-form-builder
npm install
`

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.
